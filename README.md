# 广工实验室安全 · 开卷助手

一个油猴（Tampermonkey）脚本：在实验室安全考试页面读题，比对内置题库，把答案列在右侧浮动面板里，并高亮正确选项。

**明确边界：只读标注。不自动点选、不自动交卷、不发送任何网络请求、不接触账号与密码。**

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 点击安装脚本：
   https://raw.githubusercontent.com/xianchen-jb/gdut-labsafety-helper/main/gdut-labsafety-helper.user.js

   （也可以在 Tampermonkey 的"实用工具 → 从 URL 安装"里粘贴上面的地址；或把 `gdut-labsafety-helper.user.js` 拖进浏览器窗口。）
3. 打开考试页，无需其它配置。

## 使用

- 进入 `#/exam/test/do/*` 后几秒内，右下角出现「安全考试 · 开卷助手」面板。
- 面板每行是一道题的答案，按可信度分三档：
  - `12. C 停机，重新安装后运行` —— 确信（题库精确命中，绿色）
  - `13. ≈B …（建议核对）` —— 待核对（找到相近题目，橙色，请自行确认）
- `14. 参考B 二氧化碳灭火器（相似 0.62，非题库答案）` —— 未命中，但给出"最接近题目"的答案作参考（虚线橙框）
- 面板顶部有一条提醒：`需人工核对 3 题：9、12、14`（交卷前只看这几道即可）；全命中时显示"全部命中题库，可直接交卷"。
- 卷面每题标题右侧挂对应徽章（`✓ / ≈ / ?`），确信与待核对的正确选项会高亮底色。
- 图片题按"图片指纹"匹配：若卷面那张图与题库里录过的图是同一个文件，直接命中并显示 `图✓ B …图片指纹命中`（不用看文字）。
- 面板底部实时统计：`确信 76 · 待核对 2 · 参考 1 · 无答案 0`。
- 标题栏「导出诊断」按钮：把每题的题干/选项原文、命中条目、题干相似度、选项相似度、最终判定导成 JSON，并在面板里弹出可全选复制的内容框（附「复制 / 下载文件 / 关闭」）。**纯本地生成，不上传任何数据**——出问题时把这个内容发我即可定位。
- 面板顶部标题栏可拖动；按钮不受拖拽影响（v0.3.1 修掉了"指针捕获吞掉按钮点击"的问题）。
- 点面板里的某一行 → 页面滚动到那道题并闪一下边框（只是定位，不会替你点选）。
- 拖标题栏可移动面板；`Alt + H` 或点「收起」折叠；点「重扫」强制重新匹配。

## 构建与测试

```bash
node build.mjs                 # 把 data/bank.json 注入 src/helper.core.js，产出 gdut-labsafety-helper.user.js
node test/engine.test.mjs      # 匹配引擎回归：17 个实战用例 + 全库自检
node test/recall.eval.mjs      # 扰动鲁棒性评测 + 阈值扫描 + 同题干多版本区分
node test/core.smoke.mjs       # 假 DOM 冒烟：脚本能否加载、标注、出面板
node test/inspect.mjs "关键词"  # 排查工具：看某道题的题库条目
node tools/analyze-diag.mjs <导出的诊断.json>   # 诊断归类：把没答上的题分类，指出优化方向
node tools/merge-contrib.mjs <补录.jsonl>       # 题库补录：把新题（含图片指纹）并入题库
powershell -File tools/ocr.ps1 <截图.png>       # 本地 OCR：把截图转文字（用于看图里的题目/标签）
```

对比不同版本的引擎（例如从 git 里导出旧版）：

```bash
git show <旧提交>:src/engine.js > /tmp/engine_v1.mjs
node test/recall.eval.mjs --engine /tmp/engine_v1.mjs
```

题库源数据（抓取产物）不入库；仓库里的 `data/bank.json` 是构建用数据，改完后重跑 `build.mjs` 重新生成脚本。

## 匹配引擎怎么工作

1. **归一化流水线**：全角→半角 → 繁→简 → 同义词等价（钢瓶/气瓶、触电/电击）→ 数字单位统一（100 度=100℃、中文数字）→ 去空白标点；同时生成"去括号"的核心题干视图（很多改写题只差括号里的注记）。
2. **多级索引召回**：题干精确 → 去括号精确 → 前 6 字前缀桶 → 2-gram 倒排取 top-N。2-gram 保证短题干也能召回。
3. **联合评分**：`score = 0.6 × 题干相似 + 0.4 × 选项相似`；题干相似 = 0.5×2-gram Jaccard + 0.5×最长公共子序列占比；选项相似是双向覆盖。同名题多版本靠这个分数挑"选项最吻合"的那一套。
4. **选项一一对齐**：正确项与卷面项做贪心二分匹配（不会两个正确项撞到同一项），允许题库选项在卷面缺失（标记"部分匹配"）。
5. **题干门（关键修正）**：题干相似度 ≥0.97 直接判"确信"、≥0.85 判"待核对"，**不让"卷面把选项改写"把同一道题误杀成未命中**（实测中就吃过这个亏：题干一字不差、选项被改写，分数掉到 0.62）。
6. **未命中也要给东西**：低于阈值时不再只显示一个数字，而是给出"最接近题目"的答案并明确标注「非题库答案，仅供参考」；同时列出需人工核对的题号。
7. **选项对齐自适应**：正确项与卷面项匹配时，长文本放宽阈值、短文本从严，并支持"独特片段互相包含"（如"兆欧表"），专治选项被改写/扩写。

## 实战踩过的坑（已写进代码/测试）

- **考试页与背题页的选项措辞会差几个字**（例如"安全使用操作规程" vs "使用安全操作规程"），所以选项匹配必须有相似度容错，不能只做完全相等。
- **同名题多版本**：如"预防电气火灾基本措施"有 4 套选项版本、"爆炸物品特点"有 2 套，答案随选项变化，必须逐版本比对。
- **反直觉口径**：可燃气体泄漏不能先断电、试电笔不能作为确认无电依据、无毒试剂不必按危废处理。

## 已知限制

- 图片题有两条路：**图片指纹**（同一张图直接命中，最可靠）与**题干文字**（"图中…"这类文字区分度低）。
- 已录入图片指纹的题在 `data/bank.json` 里体现为第 4 列（`[题干, 选项, 正确项, [图片指纹...]]`）。目前收录实验室安全的 2 张图片（对应 3 道题）。
- 补录新图片题：把 `{"t":"题干","opts":[...],"a":"B","img":["/chem/api/...jpg"]}` 写成 JSONL（`contrib/` 下有样例），然后
  `node tools/merge-contrib.mjs <文件>` → `node build.mjs`。若这道题的题干+选项题库里已有（如本次两题），工具会自动改成 `img-map` 只补指纹。
- 考试时图片题的指纹可以直接从「导出诊断」里拿到（字段 `imgFps`），把它连同正确答案写成上面那种 JSONL 即可入库。
- 只适配当前的页面结构（`#question-N` / `.question-options label`）；学校改版后需要改 `helper.core.js` 的"页面适配层"。
- 脚本只做本地标注，因此**修改题库后必须重新构建**；若以后要做"远端题库自动更新"，需要改用 `GM_xmlhttpRequest`。
- 未命中时只给"最接近相似度"，不猜答案；如需进一步参考，可后续加"相似题参考"与个人题库（方案 D）。

## 评测结果（`node test/recall.eval.mjs`，全量 3064 题）

把卷面做等价变形后看引擎是否仍给出同一组正确选项（按选项文本判定，不看字母）：

| 变形 | v1 | v2 | 当前 v3 |
|---|---|---|---|
| 选项乱序 | 100% | 100% | 100% |
| 全角字符 | 90.0% | 100% | 100% |
| 繁体字 | 15.2% | 100% | 100% |
| 题干去括号 | 96.9% | 100% | 100% |
| 删掉一个干扰项 | 99.0% | 100% | 100% |
| 插入空白/换行 | 100% | 100% | 100% |
| 选项被改写 | — | 100% | 100% |
| 题干+选项同时被改写（压力测试） | — | 60.4% | **75.4%** |
| **合计（20836 例）** | — | — | **96.4%，误答 0，无答案 0** |

其他指标：同题干多版本区分 **114/114**；单元用例 **21/21**；全库自检 **3064/3064**；假 DOM 冒烟 **9/9**。

两点值得单独说：

- **误答一直是 0**：所有测过的变形里，引擎没有给出过一个错误答案——要么给对，要么明说没把握。
- **"无答案"从 475 例降到 0 例**（压力测试里剩下的 754 例改成给"参考"，并标注「非题库答案」）。这正是上一轮实测里最难受的点：宁可给一个七成把握的参考，也不该什么都不说。
